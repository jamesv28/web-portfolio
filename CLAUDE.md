## 1. About this project

- **What it is:** A personal portfolio site that presents my work, background, and contact info.
- **Primary job:** Help a visitor (recruiter, client, collaborator) understand who I am and see my best work within 30 seconds.
- **Stack:** React 18+ with Vite, JavaScript (ES modules), Tailwind CSS with custom properties. No state library, no UI kit unless I ask.
- **Routing:** Single page with anchor-linked sections by default. Add `react-router-dom`.
- **Hosting:** Static build (`npm run build` → `dist/`). Must work on GitHub Pages, Netlify, or Vercel with no server. Set `base` in `vite.config.js` if deploying to a subpath.
